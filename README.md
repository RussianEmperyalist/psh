# PShell 4All

Интерактивный курс PowerShell для сисадминов и специалистов по ИБ: 16 уроков, учебная консоль, автопроверка заданий.
Прогресс хранится локально в браузере (localStorage).

## Запуск
Достаточно открыть `index.html` в браузере — страницы работают и по двойному щелчку (`file://`), и на хостинге.
Если нужен локальный сервер: `npm start` (откроется http://localhost:8000).

## Публикация на GitHub Pages
1. Загрузите всё содержимое папки в репозиторий (`index.html`, `course.html` и т. д. — в корне; папка `js/bundles` обязательна).
2. Settings → Pages → Deploy from branch → `main` / root.

## Если меняете исходники
Исходники — ES-модули в `js/`, но страницы грузят готовые сборки из `js/bundles/`.
После любых правок в `js/` выполните:

    npm install
    npm run build

## Структура
- `index.html`, `course.html`, `progress.html`, `about.html` — страницы
- `css/` — стили
- `js/course/course-data.js` — содержание уроков
- `js/powershell/` — интерпретатор и командлеты, `js/simulator/` — виртуальная система
- `js/laboratory/` — терминал и проверка заданий, `js/core/` — состояние и хранилище, `js/pages/` — скрипты страниц
- `js/bundles/` — собранные скрипты (генерируются командой `npm run build`)

## Улучшения для начинающих

Переработаны теоретические материалы всех 16 уроков:
- новые понятия объясняются простыми словами до примеров;
- команды разбираются по частям;
- добавлены пошаговые сценарии чтения кода и типичные ошибки;
- уточнены ограничения и безопасное использование команд администрирования;
- исправлены примеры теории, где несколько команд сливались в одну строку.

Дополнительно исправлены примеры, которые раньше завершались ошибкой в чистой лаборатории: путь создания файла в уроке 5 и примеры функций в уроке 12. Сборки в `js/bundles/` синхронизированы с исходными данными курса, чтобы изменения отображались при обычном открытии сайта.

## Проверка

Запустите тесты командой:

    npm test

Тесты проверяют структуру всех 16 уроков, запуск каждой команды из кнопок примеров и прохождение автопроверки с подсказкой каждого урока. Перед публикацией исходников можно пересобрать файлы командой `npm run build` после установки зависимостей (`npm install`).
